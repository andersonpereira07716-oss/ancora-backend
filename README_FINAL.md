## 📋 Próximos 2 Passos (Manuais - Mas MUITO Fáceis!)

### PASSO 1: GitHub (5 minutos)

1. **Crie conta** (se não tiver): https://github.com/signup

2. **Crie repositório**:
   - Acesse: https://github.com/new
   - Nome: `ancora-backend`
   - Deixe como **Public**
   - Clique: "Create repository"

3. **Faça push** (copie e cole no PowerShell):
   ```powershell
   $env:PATH += ";C:\Program Files\Git\bin"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/ancora-backend.git
   git push -u origin main
   ```
   **Troque `SEU_USUARIO` pelo seu usuário GitHub!**

   Quando pedir senha → Digite sua senha GitHub
